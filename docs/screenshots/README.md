# Application screenshots

This folder is reserved for screenshots captured from the real, running EcoGraph Lab application.

Suggested captures:

- Main application window
- A representative graph or visualization
- A representative analysis or results view
- Any important settings or export workflow

Please use clear, unaltered screenshots that do not expose personal information. Add the images here and link them from the repository's root README. Do not use mockups or generated interface images as substitutes for actual application screenshots.
